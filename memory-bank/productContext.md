# Product Context

## 使用者

- 负责数学建模、编程、论文写作和结果复核的团队成员；
- 成员使用不同电脑、账号及 AI 工具，需要共享一致的项目上下文。

## 核心需求

- 新成员或新 AI 会话能迅速理解当前进度；
- 数据、代码、结果和论文结论保持可追溯；
- 并行开发时减少重复劳动和合并冲突；
- 主分支始终保持可运行、可复核状态。

## 成功标准

- 从干净环境按 README 可复现主要结果；
- 每个关键结论都有脚本、参数和数据来源；
- 分支合并前完成审查、验证和 Memory Bank 交接；
- 论文清楚区分事实、假设、半合成结果和外推结论。
