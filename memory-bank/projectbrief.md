# Project Brief

## 项目目标

当前处于选题阶段。仓库用于建立统一、可复现的数学建模协作流程；确定题目后，再在本文件补充研究问题、模型主线、数据来源和评价标准。

## 核心交付物

- 可复现的数据预处理与统计分析代码；
- 选题评估记录与最终题目说明；
- 各子问题的模型、求解与验证；
- 关键图表、汇总表和不确定性分析；
- 数学建模论文及 AI 使用披露；
- 数据来源、假设、限制和运行说明。

## 边界

- 不在 Git 中保存大型原始附件、模型权重或可重新生成的中间产物。
- 不把半合成或外推数据表述为直接实验观测。
- 不以无法复现的人工调整替代模型和代码。
